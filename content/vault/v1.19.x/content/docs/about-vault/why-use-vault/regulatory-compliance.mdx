# Suporte a conformidade regulatória

@include '/why-use-vault/regulatory-compliance-small.mdx'

O Vault Enterprise oferece suporte a HSM para dispositivos com interfaces
PKCS#11 versão 2.20 ou superior com bibliotecas de integração para plataformas
Linux/amd64.
O suporte à conformidade inclui:

- Chaves raiz encapsuladas em HSM.
- Retirada de selo automática com a chave raiz encapsulada em HSM.
- Aumento de entropia a partir de módulos criptográficos externos.
- Criptografia compatível com FIPS 140-2 integrada ao binário do Vault.
- Encapsulamento de selo FIPS para parâmetros de segurança críticos.
