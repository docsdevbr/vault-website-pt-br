## Criptografe os dados

Use o Vault para implantar **criptografia como serviço** e transferir a
responsabilidade pela criptografia/descriptografia de dados de suas aplicações
para o Vault.

Com o plugin transit, o Vault pode criptografar e descriptografar dados
externos, permitindo que as aplicações criptografem seus dados enquanto os
armazenam no repositório de dados primário, o que simplifica a criptografia de
dados em trânsito e em repouso em nuvens e data centers.

## Tokenize os dados

Use o Vault para transformar e tokenizar dados de entrada com segurança,
utilizando padrões criptográficos aprovados pelo NIST, como criptografia com
preservação de formato (FPE) via FF3-1 e transformações pseudônimas, como
mascaramento de dados.

Com o plugin transform, o Vault pode realizar transformações unidirecionais que
trocam valores sensíveis por valores tokenizados independentes e com estado.
A tokenização torna o valor original irrecuperável apenas a partir do token.
Os clientes autorizados devem enviar o token para o Vault para recuperar o valor
original de um mapeamento criptográfico no armazenamento.
