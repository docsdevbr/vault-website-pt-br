## Gerencie credenciais de banco de dados

Use os plugins de banco de dados disponíveis para gerenciar credenciais de banco
de dados estáticas e dinâmicas com o Vault.

Os plugins para credenciais estáticas mapeiam funções internas do Vault
diretamente para nomes de usuário em um banco de dados.
Com funções estáticas, o Vault armazena e rotaciona automaticamente as senhas
para o usuário associado ao banco de dados, com base em um período configurável
ou cronograma de rotação.

Os plugins para credenciais de banco de dados dinâmicas geram credenciais de
banco de dados sob demanda para clientes, com base em funções pré-configuradas
no Vault.
O Vault também usa contratos de concessão para revogar e rotacionar credenciais
automaticamente ao longo do tempo.
Cada cliente acessa o banco de dados com credenciais exclusivas, facilitando o
rastreamento e a auditoria do acesso aos dados.

## Gerencie credenciais da nuvem

Mecanismos de segredos de terceiros geram dinamicamente entidades de serviço com
as atribuições de função e grupo aplicáveis mapeadas para funções internas do
Vault.
O Vault associa cada entidade de serviço a um contrato de concessão e
automaticamente rotaciona ou revoga a entidade de serviço quando o contrato
expira.

## Gerencie chaves de criptografia

Para trabalhar com provedores de nuvem, você geralmente precisa usar chaves de
criptografia emitidas e armazenadas pelo provedor em seu próprio sistema de
gerenciamento de chaves (KMS).
Você também precisa manter uma raiz de confiança dentro e fora da nuvem para a
segurança das suas aplicações.

O Vault fornece gerenciamento centralizado para a distribuição e o ciclo de vida
das chaves do provedor de nuvem, permitindo que você aproveite os recursos
criptográficos nativos de seus provedores de KMS.
