## Gerenciar identidades e entidades

O Vault oferece gerenciamento centralizado de identidades por meio do plugin de
identidade, permitindo que os clientes usem contas com diferentes provedores de
identidade para autenticar no Vault.
O plugin de identidade vincula instâncias de autenticação a uma única
representação consolidada chamada **entidade**.
As entidades são mapeadas para apelidos de contas correspondentes com provedores
de autenticação e políticas que autorizam essas entidades a executar ações no
Vault.

## Use OIDC

Use o Vault como um provedor de identidade OpenID Connect (OIDC) para permitir
que aplicações cliente que utilizam o protocolo OIDC aproveitem o Vault como
fonte de identidade.

O Vault gera tokens de ID compatíveis com OIDC para funções internas que podem
configurar declarações de token de autenticação com um sistema de modelos, TTLs
de token e mapeamento explícito para especificar chaves de assinatura.

## Use a WIF

Use o Vault com a Federação de Identidade de Carga de Trabalho (WIF) para
permitir que suas aplicações se autentiquem em serviços de nuvem com segurança
usando tokens de curta duração obtidos de um provedor de identidade (IdP)
confiável.

Ao configurar um plugin habilitado para WIF e estabelecer uma relação de
confiança entre o Vault e o provedor associado, como AWS, Azure e Google Cloud
Platform, o Vault pode trocar tokens de identidade internos por credenciais STS
de curta duração, permitindo que o plugin associado opere sem configurar o
acesso explícito a credenciais de segurança IAM confidenciais.
