# Por que usar o Vault?

O software moderno funciona graças a **segredos**.
Segredos são informações sensíveis e discretas, como credenciais, chaves de
criptografia, certificados de autenticação e outras informações críticas que
suas aplicações precisam para funcionar de forma consistente e segura.

Use o Vault para centralizar o gerenciamento de segredos e fortalecer as
implantações das suas aplicações.
