# Gerencie segredos estáticos

@include '/why-use-vault/manage-static-secrets-small.mdx'

Use o mecanismo de segredos chave/valor (`kv`) para armazenar e versionar
segredos estáticos arbitrários no armazenamento físico do Vault.
Ou use o mecanismo de segredos `cubbyhole` para vincular um segredo arbitrário a
um token de autenticação e armazená-lo no armazenamento físico configurado para
o Vault.
